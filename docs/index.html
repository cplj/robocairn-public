RoboCairn

Deterministic replay and comparison of paired recorded observations, with explicit unresolved dimensions.

Run locally

Use Python 3.10 or later. From the repository root in an activated environment:

python -m pip --isolated install --no-index --no-cache-dir --no-deps wheels/robocairn-0.1.0-py3-none-any.whl
robocairn check fixtures.json

The included manual fixtures return UNKNOWN with exit code 3. Inspect the JSON report and all unresolved dimensions. An OK result can still contain regressions.

Interfaces

  • Input schema
  • Output schema
  • Local HTTP interface: POST /check, loopback by default
Evidence scope

Manual fixture replay is a software contract example. It does not execute a simulator or establish physical fidelity, robot safety or real policy performance. Container runtime behavior remains unverified.
